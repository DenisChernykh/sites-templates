# Активные материалы Mindify

Текущий Pen содержит исходный Mindify и 20 новых экранов многостраничной версии. Статистика, имя Julia Johnson, квалификации и отзывы — демонстрационные данные референса; адаптация под Юлю не восстановлена. Дополнительная биография, контакт .example, цены, часы и данные статьи вымышлены по прямому запросу пользователя для непубликуемой наработки. Они собраны в `content/multipage.mjs` и отмечены в комментариях SPEC на холсте.

Источники изображений и их размеры зафиксированы в `reference/control/{desktop,tablet,mobile}.json` (поля src / natural / objectPosition). Локальные файлы — `images/mindify.framer.website/`. Для индивидуальной терапии на десктопе загружен отдельный исходный файл `individual-desktop.jpg`: оригинал использует другое изображение, чем мобильная версия.

Оригинальные файлы шрифта:

| Файл | Назначение |
|---|---|
| 2b02b47c7f50c758.woff2 | Apfel Grotezk / Regular |
| b28028a948385cb9.woff2 | Apfel Grotezk Mittel |
| 7a67e42dc79b056b.woff2 | Рукописная подпись, CSS family Give You Glory |
| 7f6de341cbc6058b.woff2 | Satoshi Medium, служебные элементы источника |

Аудит имён и glyph cmap — [font-audit.json](reference/control/font-audit.json). Apfel из исходного сайта не содержит нужных русских букв; в текущем английском макете используется оригинал без замены на Manrope.

SVG-иконки и стрелки скопированы из опубликованных исходных контуров, а не перерисованы. Маски Logo / Made in Framer сохранены в [framer-badge-masks.json](reference/control/framer-badge-masks.json). Декоративные исходные контуры преобразованы в редактируемые path-слои Pen.

Источник дизайна и активов: [Mindify](https://mindify.framer.website/). Это локальная контрольная реконструкция, публикация нового бренда не выполнялась. Аналитический runtime Motion используется с MIT-лицензией: [MOTION-LICENSE.md](demo/MOTION-LICENSE.md).

Старые фотографии и AI-изображения проекта Юли, оставшиеся в истории и других папках репозитория, текущим Pen и активным демо не используются.
