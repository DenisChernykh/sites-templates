# Система макетов и шаблонов сайтов

Редактируемые макеты, интерактивные прототипы и инструменты сверки интерфейсов для многостраничных сайтов.

## Возможности

- Desktop- и mobile-экраны, структура страниц и библиотека блоков.
- Описание взаимодействий, навигации и анимации.
- Скрипты визуального сравнения и подготовки графических материалов.

## Инженерные акценты

- Перевод визуального референса в согласованную систему страниц.
- Связь дизайна, контента и пользовательских сценариев.
- Автоматизация визуального контроля и подготовки интерфейса к реализации.

## Стек

JavaScript, HTML, CSS.
